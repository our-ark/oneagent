# SYRYN product page snapshot

Source: https://www.underwateraudio.com/products/syryn-mp3-player

The user requested a local recreation of this product page with OneAgent chat.
The seven merchant gallery images and public Shopify product JSON were fetched
on 2026-09-12. Images retain their original order and are served locally behind
the shop token. Product photography belongs to its original owner.

`product.json` contains the two headphone variants, their snapshot prices,
availability, and gallery image mappings. This is a dated snapshot rather than
a live inventory feed. The local page labels that date and links to the selected
variant at the merchant for current details and any purchase.

The page uses local HTML/CSS/JavaScript and the existing OneAgent chat endpoint.
No merchant checkout scripts, tracking scripts, or payment forms are embedded.
