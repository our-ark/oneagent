推荐 Bot 扩展

输入：你的个人档案、各平台想要与不想要的内容，以及商品候选。处理：形成平台偏好说明、推荐搜索词和下单前确认卡。输出：应用内建议、由你发送的 Telegram／WhatsApp 分享内容、商品页跳转与审批记录。Spotify、微信和 Amazon 的站内推荐流由各平台控制；本应用目前不直接改变其算法。

数据与执行方式

当前版本的偏好、聊天与确认卡保存在当前浏览器，可导出 JSON。它不会自动登录网站、读取私人账户或执行付款。接入外部服务时，应对每个服务单独授权，并对发送、预订和支付展示可审核的动作详情。
